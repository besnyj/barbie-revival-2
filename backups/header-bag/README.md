# Bolsa original do cabeçalho

- `shop_barbie_btn-original.swf` é uma cópia exata da animação original do cabeçalho, incluindo a bolsa. Essa é a fonte fiel para reutilizar a animação.
- `pink-bag-cutout.png` é uma versão estática em fundo transparente produzida por extração visual assistida por IA a partir da bolsa exibida pelo SWF. É uma recriação, não uma exportação pixel a pixel dos vetores originais.

O SWF original permanece também em `public/global/`, mas não é mais carregado pela home.
