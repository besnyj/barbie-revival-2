- User-reported bug: opening a Ruffle-rewritten external URL directly (e.g. `/_external/shop.mattel.com/shop/index.jsp?…`) showed nothing — `serve.py` only fell back to `index.html` for `/`, `.aspx`/`.html` or extensionless paths, so `.jsp` URLs 404'd. - User-reported bug: the Games/Fairytale thumbnail grids sat outside the pink listing panel (cards started at x=40 while the pink `agg_center.png` band starts at x=95). Standard `text-align: center` does not center block boxes. Fixed in `catalog.css` with `#itemslist{margin-left:auto;margin-right:auto}` (identical used position in every engine). Verified against the original render: first cards now at x=135/327/519/711 (page 152/344/536/728), matching the archived page exactly; pink margins now visible on both sides of the grid on Games and Fairytale; 0 console errors and 0 failed requests on all pages.
